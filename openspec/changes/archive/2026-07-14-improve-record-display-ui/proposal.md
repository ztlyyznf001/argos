## Why

`add-apm-monitors` 让 Inspector 里流动的数据从「HTTP 抓包」扩展成了「网络 + 崩溃 + 卡顿 + 资源」四类事件，但承载它们的 UI 仍是纯 HTTP 形态，由此产生三个实际可观察的问题：

1. **过滤器把 APM 事件筛没了。** 列表页顶部只有 `ALL/GET/POST/PUT/DELETE` 五个 Method chip，选中任意一个具体 method，崩溃/卡顿/资源事件全部消失——因为它们的 `method` 字段不是 HTTP 动词。用户没有任何手段按事件类型（网络/崩溃/卡顿/资源）筛选，而这恰恰是排查时最常用的维度。
2. **资源采样淹没信息流。** 资源监控默认每 2 秒采样一次，每个样本都是一条独立记录并落盘：一小时产生约 1800 条资源记录，把真正重要的 HTTP 请求与崩溃事件冲得无影无踪，同时快速耗尽 `packet-storage` 的最大记录条数上限。
3. **详情页对 APM 事件无意义。** `ArgosPacketDetailPage` 的标题是 method 徽标 + URL，主体是「请求 / 响应」双 Tab。点开一条崩溃记录，看到的是空的 method 徽标和两个与崩溃毫无关系的 Tab；卡顿的 build/raster 拆分、资源的 RSS 数值都没有专门的展示位置。

此外列表项的信息密度偏低（有 `responseSize` 但不展示、时间只到秒且无相对时间），配色大量硬编码 `Colors.grey` / 固定深色渐变，暗色模式下对比度不佳。

## What Changes

- **事件类型过滤**：列表页过滤器改为两级——先按事件类型（全部 / 网络 / 崩溃 / 卡顿 / 资源）筛选，仅当选中「网络」时才显示 HTTP Method 二级过滤。各类型 chip 上显示当前记录条数。
- **资源采样聚合**：列表中连续的资源采样不再逐条铺开，而是折叠为单条可展开的聚合项，展示区间内的采样条数、当前/峰值 RSS 与内存趋势；展开后可查看逐条采样。
- **按事件类型分派详情页**：`ArgosPacketDetailPage` 依 `record.kind` 分派——网络保留现有「请求/响应」双 Tab；崩溃展示异常消息、可复制的完整堆栈与发生路由；卡顿展示丢帧数、区间总耗时、最大单帧耗时与 build/raster 拆分；资源展示 RSS 数值与采样时间。**BREAKING**：崩溃/卡顿/资源记录的详情页不再呈现「请求/响应」Tab。
- **列表信息密度**：网络记录补充响应体大小；时间戳改为「相对时间 + 绝对时间」（如 `2 分钟前 · 14:03:22`）；慢请求与错误状态的视觉强调加强。
- **视觉与暗色模式**：统一从 `Theme.of(context).colorScheme` 取色替代硬编码灰阶，保证浅色/深色模式下的对比度；统一卡片圆角、间距与字体层级。
- **空状态去网络化**：空状态文案与图标不再假设「抓包」，按当前选中的事件类型给出对应提示。

## Capabilities

### New Capabilities
- `event-type-filtering`: 列表页按事件类型（网络/崩溃/卡顿/资源）过滤记录的行为，以及与 HTTP Method 二级过滤、搜索、路由分组的联动关系。
- `resource-sample-aggregation`: 列表中连续资源采样折叠为单条聚合项的展示规则、聚合区间的划分与展开行为。

### Modified Capabilities
- `packet-record-ui`: 详情页由固定的「请求/响应」双 Tab 改为按 `record.kind` 分派的类型化展示；列表项补充响应体大小与相对时间；空状态按选中的事件类型给出对应文案。
- `packet-visual-polish`: 配色由硬编码灰阶改为基于 `ColorScheme` 取色以适配暗色模式；新增崩溃/卡顿/资源三类事件的语义化配色与图标规范。

## Impact

- 影响文件：`lib/ui/argos_packet_list_page.dart`（过滤器、聚合、列表项、空状态）、`lib/ui/argos_packet_detail_page.dart`（按 kind 分派）；可能新增 `lib/ui/` 下的类型化详情视图与聚合组件。
- 不改动监控采集逻辑（`lib/apm/`）、数据模型（`lib/model/`）与存储层（`ArgosPacketStorage`）——本次仅改变既有数据的**展示**方式，不改变其采集与落盘。
- 资源采样的存储压力问题在本次仅从展示层缓解（聚合显示）；是否降低采样落盘频率或为资源事件设独立配额，留待后续变更评估。
- 无公开 API 变更；宿主接入方式不变。
